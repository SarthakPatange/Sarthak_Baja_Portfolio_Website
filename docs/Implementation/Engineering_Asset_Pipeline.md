# Engineering Asset Pipeline

Version: 1.0

Status: Production Standard

Purpose

This document defines the complete lifecycle of every engineering asset used throughout the portfolio.

An engineering asset should never be uploaded directly to the website.

Every asset must pass through a standardized preparation pipeline to ensure consistency, quality, accessibility and performance.

The website is only the final presentation layer.

# Engineering Context

Every uploaded asset must answer

Why was this created?

What engineering question does it answer?

Where should it appear?

What evidence supports it?

---

# Repository Rules

No undocumented asset.

No duplicated asset.

No temporary asset.

No unexplained engineering figure.

No screenshots replacing raw engineering data when raw data exists.

---

# Review Checklist

Can the visitor understand it?

Is the engineering context clear?

Is the file optimized?

Is metadata complete?

Is evidence attached?
