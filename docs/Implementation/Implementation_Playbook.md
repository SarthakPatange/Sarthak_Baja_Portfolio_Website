# Implementation Playbook

Every new feature follows the same lifecycle.

Research

↓

Design Review

↓

Engineering Review

↓

Asset Preparation

↓

Implementation

↓

Accessibility Review

↓

Performance Review

↓

Creative Review

↓

Merge

Never skip stages.

---

Before writing code ask

What engineering question is this feature solving?

If no answer exists,

do not build it.

---

After implementation ask

Did engineering become easier to understand?

If not,

iterate again.

---

Every pull request should answer

Why does this exist?

How does it improve understanding?

What engineering evidence supports it?

What performance cost does it introduce?

What accessibility implications exist?

Could this be simpler?

If yes,

simplify.

---

Definition of Done

Engineering communicates clearly.

Animation explains.

Typography leads.

Performance remains excellent.

Accessibility passes.

No AI slop.

No unnecessary dependencies.

Evidence supports every claim.

The feature feels inevitable.

Not merely impressive.
