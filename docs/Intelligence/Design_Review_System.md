# Design Review System

Every completed feature undergoes five reviews.

---

Stage 1

Engineering Review

Does this improve engineering understanding?

---

Stage 2

Visual Review

Is hierarchy obvious?

Is typography leading?

Is whitespace intentional?

---

Stage 3

Interaction Review

Does interaction educate?

Does motion explain?

---

Stage 4

Performance Review

Does every dependency justify itself?

Is animation smooth?

Are assets optimized?

---

Stage 5

Honesty Review

Is every engineering claim supported?

Are limitations acknowledged?

Would this withstand technical scrutiny?

---

If any stage fails,

the feature returns for redesign.

Not polish.

Redesign.
