# Engineering Annotations

Purpose

Annotations explain engineering.

Not interfaces.

Every annotation answers one engineering question.

Never describe the obvious.

# Positioning

Annotations should never cover geometry.

Prefer

Outside

↓

Leader Line

↓

Component

Avoid

Floating labels.

Centered labels.

Large text blocks.

---

# Animation

Fade

↓

Slide

↓

Remain stable

Never bounce.

Never pulse.

Never glow.

# Rules

Engineering remains visible.
