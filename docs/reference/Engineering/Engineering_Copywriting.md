# Engineering Copywriting

Purpose

Engineering writing should communicate thinking.

Not marketing.

---

# Voice

Professional.

Confident.

Curious.

Honest.

Evidence driven.

---

# Preferred Language

We evaluated.

We selected.

We validated.

We measured.

We observed.

We improved.

---

Avoid

Amazing

Innovative

World Class

Next Generation

Game Changing

State of the Art

Cutting Edge

---

# Headlines

Should communicate engineering.

Bad

Suspension System

Good

Designing Suspension for Predictable Vehicle Behaviour

---

Bad

Telemetry

Good

Building an Embedded Data Acquisition Platform

---

# Paragraph Structure

Context

↓

Problem

↓

Decision

↓

Evidence

↓

Outcome

---

# Numbers

Every number answers

Compared to what?

Measured how?

Validated where?

Never publish isolated numbers.

---

# Repository Rules

Write like an engineer.

Not a marketer.

Never exaggerate.

Never oversell.

Always provide context.

Evidence first.

Claims second.
