# Engineering Performance Guidelines

Purpose

Performance is a user experience feature.

Not an optimisation task.

---

# Asset Budget

GLB

<15 MB preferred

Hero Images

<500 KB

Videos

Compressed

Deferred

Telemetry

Streamed

Charts

Generated

Not screenshots

---

# Rendering

Lazy load

Intersection Observer

Progressive enhancement

GPU transforms

Texture compression

Draco compression

KTX2 textures

---

# Animation Budget

Maximum

One narrative animation

One supporting animation

One ambient animation

Never exceed.

---

# Performance Rules

60 FPS minimum.

Avoid layout thrashing.

Avoid unnecessary JavaScript.

Reduce dependencies.

Use browser caching.

---

# Repository Rules

Performance before decoration.

Fast before flashy.
